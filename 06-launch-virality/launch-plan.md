# Launch plan — J-7 → J+90

Six phases. Don't half-launch: a partial run does not produce 10k stars.
Checklists to tick: [`../templates/launch-checklist.md`](../templates/launch-checklist.md).

## Phase 0 — Build (S-4 → S-1)

| When | Action | Done when |
|---|---|---|
| S-4 | Freeze v1 scope: README + playbooks 1-3 + 10 skills + Part 2 + Part 5 (payments 10 countries, pan-Afr grants). | Launch-ready checklist ticked |
| S-4 | Identity: repo name, tagline, simple logo, og-image, colour. | Assets in `/assets` |
| S-3 | Write `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, 20 draft `good first issue`s, issue/PR templates. | Committed |
| S-3 | GitHub Actions: welcome, link-check, stale, All-Contributors. | CI green |

| S-2 | Draft: "Show HN", X thread (10 tweets), LinkedIn post, PH text, 5 community messages, newsletter #1. | `post-templates.md` filled |
| S-1 | Build the **100-supporter list** (name, channel, relationship, J0 slot). Personal DM each. | 100 "yes" / "will look" |
| S-1 | Pre-fill Product Hunt draft (scheduled). Warn 3 Africa communities of "something Tuesday". | PH draft ready |
| S-1 | Dry run: someone clones the repo cold in 15 min, logs frictions. | Frictions fixed |

## Phase 1 — Soft launch (S0, Monday)

| Time (UTC) | Action |
|---|---|
| Mon 09:00 | Make the repo public **quietly**. Share in **5 Africa communities** with a "feedback wanted" framing — not "star me". |
| Mon daytime | Reply to every piece of feedback. Open issues from it. Fix the README if a point recurs twice. |
| Mon evening | Debrief: what lands / what blocks? Adjust hard-launch copy. Aim for 100-300 organic stars. |

## Phase 2 — Hard launch (S1, **Tuesday**)

| Time (UTC) | Action |
|---|---|
| 08:00 | Product Hunt live (00:01 PT). Title + tagline + first comment = founder story. Notify 30 supporters for the first hour (comment, not just upvote). |
| 13:00 | Post "Show HN" (exact title from Playbook 6). Stay on HN 4-6h, reply to everything in < 15 min, humble tone, never defensive. |
| 13:15 | X thread + LinkedIn post + newsletter. Pin the thread. |
| 13:30 | Post in 10 communities (5 from Monday + 5 new) + relevant subreddits. One tailored message each, never identical copy-paste. |
| 14:00-02:00 | War room: reply everywhere in < 15 min. Thank every contributor by name. Tweet milestones ("500 ⭐ in 3h, thank you 🇧🇯"). |
| 22:00 | Update README with first testimonials / "trending #X". |

## Phase 3 — Momentum (S2 → S8)

| Cadence | Action |
|---|---|
| Weekly | **1 new playbook OR 1 new country** merged and announced (thread + newsletter + community). |
| 2×/week | 1 X thread + 1 LinkedIn post (`/create-viral-hook`): teardown, number, resource, story. |
| Weekly | 15-20 `good first issue`s open at all times. Review < 24h. Contributor spotlight. |
| Week 2 | Submit to relevant awesome-lists (awesome-startup, awesome-entrepreneurship, awesome-africa, awesome-claude, awesome-ai-tools). One PR each. |
| Week 3 | Pitch TechCabal / Disrupt Africa / Benjamindada / Techpoint / Rest of World (email + angle "Benin founder open-sources the OS for African founders"). |
| Week 4 | One collab: co-write a guide with another repo/newsletter (audience swap). |
| Weeks 5-8 | Launch the country-ambassador program (5-10 countries). |
| Weeks 5-8 | Publish the first case study (RESTAFY or an early user). |

## Phase 4 — Scale (S9 → S20)

- 1 institutional partnership: an accelerator adopts the OS as a cohort resource (co-branding, workshop).
- Freeze FR+EN, open PT (Angola/Mozambique) and maybe AR via contributors.
- Spin up "Founder OS Weekly" newsletter — audience capital detached from GitHub.
- Possible PH/HN round 2 on a sub-product (packaged skills, standalone payments-adapter).
- Propose a talk (GITEX Africa, Moonshot, DevFest) "Building in public from Benin".

## Phase 5 — Consolidation (S21 → S26)

- Turn on GitHub Sponsors + Open Collective; publish a "sustainability" page.
- Publish roadmap v2 (open RFC) → re-engages the community.
- Quality audit: global link-check, dedup, `last_checked` on every Africa entry.
- Public 6-month recap (thread + article) = a fresh spike + credibility.
