# Cold email — 3-touch sequences

Warm the inbox first (2-3 weeks). Max 10-20/day/inbox. Plain text. No images, no tracking pixels
if deliverability matters. Follow-ups in the same thread.

## Sequence A — Casual

**T1 (day 0)** · Subject: `quick one about [company]`
```
Hi [First name],
[HOOK: one specific, observed detail].
We help [segment] [outcome]. [Peer] went from [before] to [after] in [time].
Worth a 15-min call, or should I send a 1-pager?
[You]
```
**T2 (day 3)** · same thread
```
Bumping this — a 1-line example: [mini case study].
```
**T3 (day 7)** · same thread
```
I'll stop here. If [problem] becomes a priority, I'm around. A useful link meanwhile: [repo resource].
```

## Sequence B — Numbers / proof

**T1** · Subject: `[metric] for [company]?`
```
Hi [First name],
[Segment] using [Product] see [specific result: e.g. "12% fewer missed orders in month 1"].
Given [observed detail about their business], thought it might be relevant.
Open to a short call this week?
```
**T2 (day 3):** attach/paste a 3-line case study.
**T3 (day 7):** "Closing the loop — happy to reconnect whenever timing's better."

## Sequence C — Short question

**T1** · Subject: `how do you handle [problem] at [company]?`
```
Hi [First name], genuine question — how are you handling [problem] today?
Asking because we built [Product] for it and I'm trying to learn what people actually do.
```
**T2 (day 4):** "Still curious about the above — even a one-word answer helps."
**T3 (day 8):** "No worries if not. Here's [resource] in case it's useful."

## Rules to avoid
Sending all touches in 24h · "Hope this email finds you well" · a paragraph before the ask ·
generic merge fields with no real personalisation · sending Friday afternoon local time.
