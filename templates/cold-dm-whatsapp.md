# Cold WhatsApp — 5 variants

Rules: < 60 words · personalise line 1 with an [OBSERVABLE HOOK] · problem before product ·
one soft question · send 09:00-11:00 or 15:00-17:00 local · follow up once at D+3.

**V1 — Direct**
```
Hi [First name], I'm [You], building [Product] in [City].
Saw [HOOK: your evening order queue / your new branch].
We help [segment] [outcome: stop losing orders].
15 min this week to hear how you handle it today? Not selling — just understanding.
```

**V2 — Voice note offer**
```
Hi [First name] 👋 [HOOK]. I built something for [segment] around [problem].
Easier if I send a 40s voice note explaining? Or a quick call whenever suits you.
```

**V3 — Peer reference**
```
Hi [First name], [Mutual / peer business] mentioned you might have the same issue with
[problem]. I'm working on [Product] for exactly that. Worth a short chat?
```

**V4 — Free-value first**
```
Hi [First name], I put together a 1-pager on [useful local thing: mobile-money fees compared /
grants closing this month]. Happy to send it. Also building [Product] for [segment] — curious
if [problem] is on your plate.
```

**V5 — Follow-up (D+3)**
```
Bumping this once, [First name]. Quick example: [peer] cut [pain] by [result] with it.
If it's not a priority now, all good — I'll leave it here.
```

## 8 observable hooks (adapt per sector/country)
new opening · recent Google/Facebook reviews · active Instagram · hiring post · running a promo ·
long WhatsApp response time when you messaged as a customer · featured in a local article · new location on Maps.
