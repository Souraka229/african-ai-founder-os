# Launch checklist

## Repo launch-ready (before S0)
**Content**
- [ ] README: banner, badges, tagline, 15s GIF, 3 paths, "contribute in 1 PR", star-history, license
- [ ] `00-start-here/README.md` tested by an outsider in < 15 min
- [ ] Playbooks 1, 2, 3 complete and proofread
- [ ] 10 skills: prompt + example I/O + installable format
- [ ] Part 2: at least ai-tools, boilerplates, payments-africa, cloud-credits
- [ ] Part 5: payments for ≥ 10 countries, pan-African grants, ≥ 3 regulation notes
- [ ] ≥ 8 templates (incl. `payments-adapter.ts`, `interview-guide.md`, this file)
- [ ] FR + EN for README + `00-start-here` + 1 playbook

**GitHub infra**
- [ ] `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `CHANGELOG.md`
- [ ] 5 issue templates + PR template
- [ ] Workflows green: welcome, link-check, data-lint, stale, metrics-snapshot
- [ ] `data/schema/*` + validation passes
- [ ] All-Contributors initialised
- [ ] 20 `good first issue`s drafted, 15 published on hard-launch day
- [ ] GitHub topics (20) + description (350 chars)
- [ ] "Template repository" enabled
- [ ] `LICENSE` (MIT) + `LICENSE-CONTENT` (CC BY 4.0)

**Marketing**
- [ ] Landing page live (captures emails) + og-image
- [ ] Domain redirect configured
- [ ] `post-templates.md` filled: Show HN, X thread, LinkedIn, PH, 10 community messages, newsletter #1
- [ ] 100-supporter list (name, channel, J0 slot) — 30 confirmed for hour 1
- [ ] Product Hunt draft scheduled (00:01 PT Tuesday)
- [ ] 5 Africa communities pre-warned (soft launch Monday)
- [ ] Newsletter connected, first issue ready
- [ ] Dub.co campaign links (one per channel)
- [ ] Landing analytics + PostHog

## Hard-launch day (Tuesday)
- [ ] 08:00 UTC — Product Hunt live, first comment = founder story, 30 supporters notified
- [ ] 13:00 — "Show HN" posted, war room open
- [ ] 13:15 — X thread pinned + LinkedIn post + newsletter sent
- [ ] 13:30 — 10 communities + subreddits (message tailored to each)
- [ ] Every 30 min — reply everywhere, < 15 min lag
- [ ] Milestones tweeted (500 / 1,000 / 2,000 ⭐)
- [ ] Every contributor/commenter thanked by name
- [ ] 22:00 — README updated (testimonials, "trending")
- [ ] EOD — feedback turned into issues, undecided followed up

## Weekly (S2 → S8)
- [ ] 1 new playbook OR 1 new country merged + announced
- [ ] 2 X threads + 1 LinkedIn post
- [ ] 15-20 GFIs open; issues answered < 24h; PRs reviewed < 72h
- [ ] 1 contributor spotlight
- [ ] 5 personalised partner/press contacts + D+4 follow-ups
- [ ] Metrics snapshot reviewed
- [ ] Dead links fixed (CI)
- [ ] 30 min community: welcome new members, "Friday win"
