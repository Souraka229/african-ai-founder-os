# Playbook 7 — Funding (grants → accelerators → pre-seed)

Pairs with skill [`/generate-pitch-deck`](../04-ai-skills/generate-pitch-deck.md),
[`../templates/grant-application.md`](../templates/grant-application.md),
[`../templates/one-pager.md`](../templates/one-pager.md), and the
[Africa funding lists](../05-africa/grants-by-country.md).

**Objective:** secure $5-50k non-dilutive in 60-120 days, or get into one accelerator, or close a pre-seed.

**Prerequisites:** minimal traction (active users OR revenue OR LOIs), one-pager, 10-12-slide deck,
a registered company (or in progress).

## Steps

1. **Week 1 — Map it.** List 15-20 opportunities (see Part 5) sorted by: amount, dilution (0 first),
   deadline, geo/sector fit, application effort.
2. **Week 1 — Reusable base assets:** one-pager, deck, 2-min video, canned answers (problem,
   market, traction, team, use of funds, impact).
3. **Weeks 2-8 — Apply in waves:** 3 applications/week. Personalise the intro and the "impact"
   section per program. Track in a table.
4. **Ongoing — Network:** 5 warm intros/week (mentors, program alumni, other founders). Grants
   and accelerators also select on referral.
5. **For pre-seed:** target 20-30 angels/micro-VCs active in Africa, run the raise over 6-8 weeks,
   create momentum ("closing on [date]").

## Template — "use of funds" section

```
Of [amount]:
- 50% product (2 AI devs, 4 months) → target: X → Y on [metric]
- 25% go-to-market ([proven channel]) → target CAC, [N] clients
- 15% operations / compliance ([country])
- 10% buffer
6-month milestones: [MRR], [active users], [1 retention proof]
```

## Success metrics

≥ 12 applications submitted · ≥ 3 shortlists · ≥ 1 funding/program won · angel pipeline ≥ 20.

## Traps

One generic copy-pasted application · going for equity before exhausting non-dilutive · underestimating
disbursement time (often 2-4 months) · neglecting compliance (KYB, registration) that blocks payout.
