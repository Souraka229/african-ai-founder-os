# Security Policy

This repository contains documentation, templates, and structured data — not a running
service. The main risks are:

1. **Malicious links** in contributed data. If you find a link that points to phishing,
   malware, or a scam, open an issue with the `report-outdated` template or email
   **security@africanaifounder.dev**. Do not open a public PR that "fixes" it silently.
2. **Bad advice in a template** (e.g. an insecure `payments-adapter` snippet). Report it
   the same way; we'll patch and credit you.

Please give us a reasonable window to address the issue before disclosing publicly.
