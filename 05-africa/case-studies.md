# Case studies — African startups

Short, lesson-first. Contributions welcome (add sources, numbers, and new cases).

| Startup | Country | Lesson to steal |
|---|---|---|
| **Paystack** | NG → acquired by Stripe (~$200M, 2020) | Flawless DX + focus one country first + docs = moat. |
| **Flutterwave** | NG → unicorn (~$3B) | Pan-African "rails" infra; bank/telco partnerships; country-by-country expansion. |
| **Jumia** | NG / pan-Afr → NYSE | Logistics + cash-on-delivery = adapting to the ground; burns cash → watch unit economics. |
| **M-Pesa (Safaricom)** | KE | Agent-network distribution + a simple P2P use case → massive network effect. |
| **Wave** | SN / CI → unicorn | Break prices (near-zero fees) in a high-margin market → viral adoption. |
| **Andela** | NG / pan-Afr | Talent as a product; successive pivots (bootcamp → marketplace). |
| **mPharma / Field Intelligence** | GH / NG | B2B health: integrate the existing (pharmacies) rather than disintermediate. |
| **Kuda / FairMoney / Moniepoint** | NG | Neobank / agent banking: compliance + agent distribution = the barrier. |
| **Chipper Cash** | pan-Afr | Remittance + diaspora network effect; heavy regulatory sensitivity. |
| **RESTAFY** | BJ | *To be written as it happens — your social proof and your content.* |
