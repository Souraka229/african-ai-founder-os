# Part 10 — Monetization & Sustainability

Full version: [`../MASTER-DOC.md`](../MASTER-DOC.md#part-10--monetization--sustainability).

**Principle:** the core (playbooks, skills, Africa layer) stays **free and open forever**.
We monetize the *service* — workshops, guidance, premium community, aggregated data for B2B —
never access to the knowledge.

## Levers (activation order)

| Lever | Activate when | 12-month potential |
|---|---|---|
| GitHub Sponsors + Open Collective | ~2,000 ⭐ | $300-1,500/mo |
| Paid workshops ("idea → MVP in 7 days", cohorts) | 500-member community | $500-3,000/session |
| B2B to accelerators (program licence + facilitation) | after 1 pilot | $2,000-10,000/program |
| "OS Circle" paid community (office hours, deal flow, intros) | after 1,000 free members | $10-20/mo × 100-300 |
| Tool sponsors (labelled section, never in neutral picks) | after proven traffic | $200-1,000/mo/sponsor |
| Open-source grants (Sovereign Tech Fund, GitHub Fund, ecosystem) | ~3,000 ⭐ + proven usage | $5k-50k one-off |
| "Founder OS Pro" (light SaaS: progress dashboard, cohorts) | year 2 | MRR |

## Funding platforms

GitHub Sponsors (0% fee) · Open Collective (transparent budget + fiscal host) · Ko-fi / BMC ·
Polar.sh (sell templates/guides) · Liberapay · Gumroad / LemonSqueezy (Merchant of Record, handles VAT).

⚠️ **Africa constraint:** GitHub Sponsors / Stripe payouts aren't available everywhere (check for
Benin at the time). Workarounds: (a) Delaware entity via Stripe Atlas, (b) Open Collective fiscal
host, (c) Polar/LemonSqueezy as Merchant of Record, (d) a trusted partner in an eligible country.
Keep this note current here.

## Sustainability roadmap

| Horizon | Goal | Actions |
|---|---|---|
| 0-6 mo | Pure growth, no intrusive monetization | Open Sponsors at 2k ⭐ (discreet), 1 paid pilot workshop, document impact |
| 6-12 mo | $500-2,000/mo recurring + 1 grant | OS Circle, 1-2 labelled tool sponsors, apply to 2 OSS grants, 2-3 workshops/quarter, 1 accelerator deal |
| 12-24 mo | Fund 1 part-time maintainer + paid contributors | OSS grant secured, recurring B2B, "Founder OS Pro" beta, sponsored newsletter, RFC governance |
| 24 mo+ | Lean, durable org | Legal entity, 1-2 part-time salaries, contributor budget, annual event |
