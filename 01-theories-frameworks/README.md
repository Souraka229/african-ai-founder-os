## Open-source virality (how repos hit 10k ⭐)

- **7 patterns 0→10k:** README-as-product · solve pain not features · launch on **Hacker News first**, Tue-Thu 8-10 ET · 5-minute onboarding · awesome-list positioning · balanced docs (no wiki) · reply to every issue < 24h.
- **Star Velocity Loop:** GitHub surfaces *acceleration*, not totals → concentrate stars in a 72h window (100 pre-briefed supporters, all triggered the same Tuesday).
- **Growth loops > funnels:** every skill/template/playbook carries a native share mechanism ("Made with african-ai-founder-os").

## Startup validation

The Mom Test · Lean Startup (Build-Measure-Learn) · Jobs To Be Done · Value Proposition Canvas ·
Sean Ellis PMF test (≥40% "very disappointed") · Fake Door / Smoke test · Riskiest Assumption
Test (RAT) · Continuous Discovery (1 interview/week).

## Growth models

**PLG** (product acquires/activates) · **CLG** (community is the channel — *the engine of this repo*) ·
**SLG / hybrid** (sales for high ACV). Table of ACV × channel × north-star metric in the master doc.

## Pricing

Value-based · Competitive · Cost-plus · **Van Westendorp PSM** (4 questions, ~30 respondents) ·
price laddering (Good-Better-Best) · freemium threshold. **Africa rule:** price in local currency
+ a low monthly mobile-money tier — cash-flow beats total price.

## Open-source contributor psychology

Motivators, in order: reputation/signaling · scratch-your-own-itch · belonging/identity ·
learning · cause. Levers: always-stocked `good first issue`, All-Contributors bot, monthly
spotlight, < 24h reply, ultra-scoped contribution templates.
