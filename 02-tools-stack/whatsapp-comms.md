# WhatsApp & communication — Africa-first

Full table in [`../MASTER-DOC.md`](../MASTER-DOC.md#28-whatsapp--communication-afrique-first-top-12).

| Tool | Use | ~Price | Africa note |
|---|---|---|---|
| **WhatsApp Business App** | Catalog, quick replies, labels | Free | #1 informal sales channel |
| **WhatsApp Cloud API (Meta)** | Templates, automations, multi-agent | Free access + per-conversation fee | Base of any serious WhatsApp bot |
| **360dialog** | BSP (API access), no per-message markup | ~€49/mo + Meta cost | Transparent, popular |
| **Twilio** | WhatsApp/SMS/voice API | usage | Reliable, great docs, pricey |
| **Africa's Talking** | SMS, USSD, voice, airtime — pan-African API | low usage | The SMS/USSD reference (KE, NG, UG…) |
| **Termii** | SMS/OTP/WhatsApp/voice, Africa-optimized delivery | usage | Strong delivery NG + West Africa |
| **Sendchamp** | Multichannel (SMS, WhatsApp, email, OTP) | usage | NG-first |
| **Wati / AiSensy / Interakt** | No-code WhatsApp CRM on Cloud API | $39-99/mo | Bots, broadcasts, catalog |
| **Chatwoot** | Omnichannel support (**open source**) | self-host free / $19/agent | Self-host = controlled cost |
| **Typebot** | Visual chatbot builder (**OSS**) | freemium | WhatsApp flows |
| **Africa's Talking USSD** | Menus for feature phones (no internet) | usage | Reach non-smartphones |

**Recommended for a B2C / B2SMB SaaS in Africa:** bot on **Cloud API via 360dialog or Termii**,
support on **Chatwoot self-host**, transactional OTP/SMS on **Africa's Talking / Termii**.
