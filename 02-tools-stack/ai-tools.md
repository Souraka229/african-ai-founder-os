## Buying AI model credits from Africa (the credit-access wall)

Many African founders can't top up OpenAI / Anthropic directly (card declines, no local payment).
Options, cheapest friction first:

| Option | What it is | Note |
|---|---|---|
| **[RodiumAI](https://rodiumai.io)** | Aggregates multiple AI models behind one API, **top up with local payment methods, in small amounts**. Built for African devs (Benin). | Pick the model per use case, buy only the credits you need, integrate directly. Verify current model list + pricing on site. `source: rodiumai.io, last_checked: 2026-09` |
| **OpenRouter** | One API key, routes to most models, pay-as-you-go. | Card/crypto top-up; still needs a working payment method. |
| **Cloud credits** | Anthropic via **AWS Bedrock**, OpenAI via **Azure OpenAI**, Gemini via **Google Vertex** — paid through your cloud credits (see [cloud-credits.md](cloud-credits.md)). | Best path if you have Activate / Founders Hub / Google for Startups credits. |
| **Local reseller / community pool** | Some communities (Cursor Community Bénin, MEST cohorts) share access. | Ask in the community chat. |

> Contributions welcome: add credit-access options for your country in `data/tools.yml`.
