# Recommended stack by scenario

Full detail in [`../MASTER-DOC.md`](../MASTER-DOC.md#29-stack-recommandée-par-scénario).

## A — Bootstrap solo, < $20/mo

- **Build:** Claude Code + `ixartz/SaaS-Boilerplate` or `rk-kit` (free) + Supabase free + v0.
- **Deploy:** Vercel hobby / Cloudflare Pages + Supabase free.
- **Pay:** Paystack (NG/GH/KE) or KkiaPay/CinetPay (Francophone).
- **Measure:** Clarity + PostHog free + GoatCounter.
- **GTM:** WhatsApp Business App + Tally + Dub + manual X/LinkedIn.
- **AI credits:** RodiumAI / OpenRouter.

## B — Post-grant / accelerated, ~$500-2000/mo, non-dilutive

- **Build:** Claude Code + Cursor + MakerKit (multi-tenant) + Supabase Pro.
- **Deploy:** Vercel Pro + Supabase Pro + Cloudflare R2.
- **Credits:** activate AWS Activate Portfolio + Google Cloud + Azure via the accelerator.
- **Pay:** abstraction layer + Flutterwave (pan-Afr) + one local provider.
- **Measure:** PostHog paid + Metabase on the DB.
- **GTM:** Apollo/Instantly + Clay (if B2B) + Cal.com + HubSpot Startups.
- **Comms:** WhatsApp Cloud API via 360dialog + Wati + Termii.

## C — AI-first (the product IS an agent)

- **Build:** Claude Code + Claude/OpenAI via **OpenRouter/RodiumAI** + Langfuse + Trigger.dev.
- **AI infra:** Modal/Replicate GPU + NVIDIA Inception credits + Google AI-first ($350k).
- **Vector/DB:** Supabase pgvector or Turso + Upstash (Redis/queues).
- **Deploy:** Vercel (front) + Fly.io/Modal (AI workers).
- **Measure:** PostHog + LangSmith/Langfuse (answer quality).

## D — Funded pre-seed (with a VC)

- Unlock all credit tiers (AWS GenAI $300k, Google $350k, Azure $150k).
- HubSpot CRM, data stack (RudderStack + warehouse + light dbt), Sentry Team, Statsig.
- Talent: Africa hiring + Deel/Remote for contracts; Mercury/Brex for banking.
