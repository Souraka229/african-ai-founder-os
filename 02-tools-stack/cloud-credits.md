## How to unlock the big tiers without a VC

1. **Join a partner accelerator** — even 100% remote and non-dilutive ones (see [`../05-africa/accelerators.md`](../05-africa/accelerators.md)). Google for Startups Accelerator Africa, MEST, CcHUB unlock partner credits.
2. **Community programs** that need no VC: Microsoft tier 1 ($1k), DigitalOcean Hatch, MongoDB.
3. **Stack them:** AWS + Google + Azure combined can exceed **$500k** for an accelerated startup.
4. **Use credits to pay for AI:** Anthropic via Bedrock, OpenAI via Azure OpenAI, Gemini via Vertex — see [`ai-tools.md`](ai-tools.md).
